# KVRC Jewellers

Website for KVRC Jewellers, Chittapara, Chittoor, Andhra Pradesh.
Built with TanStack Start, React, Tailwind CSS and shadcn/ui.

Designed & built by Mazent.

## Edit shop details

Open `src/routes/index.tsx` and edit the `SHOP` object at the top:
WhatsApp number, phone number, opening hours and the daily gold and silver rates.

## Product photos

Replace the images in `src/assets/` (keep the same file names) with your own photos.

## Run locally

```sh
npm install
npm run dev
```

## Build for production

```sh
npm run build
```
